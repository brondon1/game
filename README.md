# 像素地牢

一个类似《元气骑士》的 2D 俯视角 Roguelike 地牢射击游戏骨架，用 **Godot 4.7** 开发。

美术使用 0x72 的免费像素素材包 [16x16 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)（CC0，可商用，详见 `assets/0x72/LICENSE.md`）；枪械、子弹、特效等素材包里没有的东西，以及音效和背景音乐，是程序生成的占位素材。玩法流程已经完整：

> 主菜单选角色 → 随机地牢（带小地图）→ 进房间锁门、分波刷怪 → 清完开门（可能掉补给箱）→ 宝箱房开金宝箱 → 商店花金币 → 打 Boss → 传送门 → 强化三选一 → 下一层 → 第 3 层 Boss 后通关 / 死亡结算 → 记录最高纪录

## 运行

1. 用 Godot 4.7 打开本目录下的 `project.godot`
2. 按 F5 运行（主场景是 `ui/main_menu.tscn`）

| 敌人（外观） | 场景文件 | 行为 | 出现楼层 |
|---|---|---|---|
| 沼泽史莱姆 | slime | 直接冲向玩家 | 1 层起 |
| 小恶魔 | bat | 飞得快、走 S 形路线，血少 | 1 层起 |

| 大僵尸 | splitter | 死后分裂成两只小僵尸 | 2 层起 |
| 角魔 | spiker | 定时鼓起身子，向四周放一圈子弹 | 2 层起 |
| 哥布林 | bomber | 向玩家位置抛炸弹，落点先出现红圈预警再爆炸 | 2 层起 |
| 死灵法师 | summoner | 保持距离，定时召唤小恶魔（最多 4 只） | 3 层起 |

## 项目结构

```
autoload/
  events.gd            全局信号总线（玩家死亡、房间清空、Boss 血量、屏幕震动）
  game_state.gd        一局的状态：所选角色、血量/护盾/能量、武器、楼层、Buff 列表、存档
  sound.gd             音效和背景音乐管理器，音量设置
characters/            角色数据（CharacterData）：骑士、游侠、法师、刺客、工程师、狂战士
skills/                技能基类 skill.gd，以及双持、翻滚、元素新星、影袭、部署炮台（turret.gd）、狂暴
player/                玩家：移动、自动瞄准、射击、技能、受伤、护盾回复、拾取武器
weapons/
  weapon_data.gd       武器数据（Resource）
  data/*.tres          14 把武器的数据
  weapon.gd            按 WeaponData 开火、挥砍或突刺，带枪口火光（玩家和敌人都能用）
  bullet.gd            子弹：阵营决定和谁碰撞；可开启爆炸、反弹、减速、追踪
enemies/
  enemy.gd             敌人基类：出生预警、追击、接触伤害、闪白、击退、掉落
  gunner.gd / bat.gd / charger.gd / splitter.gd / spiker.gd / bomber.gd / summoner.gd
                       各种敌人的 AI（bomb.gd 是炸弹哥布林扔的炸弹）
  boss.gd              Boss：追击 / 环形弹幕 / 扇形连射 循环
dungeon/
  dungeon_generator.gd 随机游走生成房间布局，最远的房间是 Boss 房
  obstacle_layouts.gd  房间障碍物布局：石柱和木箱
  dungeon.gd           把布局铺成 TileMap、挖走廊、放门和障碍物、烘焙导航网格，处理过关/死亡流程
  room.gd              房间：进门锁门、分波刷怪、清空开门；宝箱房放金宝箱；商店房放商人和商品
  door.gd / portal.gd  门、传送门
pickups/               金币、能量、药水、地上的武器
props/                 木箱（可打碎）、宝箱（按 E 打开）、墙上的火把
shop/                  商店商品（武器、药水、能量瓶、神秘强化）
common/                命中粒子、挥砍刀光、爆炸、飘字、脚下阴影、受击闪白 / 暗角 shader、光照贴图、震屏相机
ui/                    主菜单、HUD、小地图、全屏地图、Buff 三选一、暂停菜单、结算
assets/sprites/        占位像素图（可直接替换）
assets/audio/          占位音效和背景音乐（可直接替换）
default_bus_layout.tres 音频总线：Music、SFX
```

**碰撞层**（在 项目设置 → Layer Names → 2D Physics 里有命名）：
1 墙和门 · 2 玩家 · 3 敌人 · 4 玩家子弹 · 5 敌人子弹 · 6 掉落物

## 怎么扩展

**加一把新武器**：在 `weapons/data/` 里右键新建一个 `WeaponData` 资源，填写伤害、射速、能耗、子弹数、散射等参数，然后把它加进 `autoload/game_state.gd` 的 `weapon_pool`。宝箱房会随机掉落它，不需要写代码。

**子弹特效**：`WeaponData` 的“子弹特效”分组里可以设置子弹贴图、爆炸半径、反弹次数、减速时间、追踪转向速度，这几项可以随意组合（比如会反弹的爆炸弹）。

**加一把近战武器**：同样新建一个 `WeaponData` 资源，勾选“近战”分组里的 `is_melee`，再设置挥砍半径、扇形角度、击退倍率，以及能不能打掉敌人的子弹（骑士剑可以，大铁锤不行但伤害高、击退远）。近战武器只用到射击参数里的伤害、射击间隔和能耗。扇形角度不超过 60° 的武器（比如长矛）会播放往前刺的动画，其余是左右挥砍。

**加一个新角色**：在 `characters/` 里新建一个 `CharacterData` 资源，设置贴图、属性、初始武器和技能场景，再把路径加到 `game_state.gd` 的 `CHARACTER_PATHS`，主菜单会自动出现。

**加一个新技能**：新建一个脚本 `extends Skill`，在 `_activate()` 里写效果；有持续时间的技能在 `_end()` 里撤销效果。然后新建一个场景，根节点是 Node 并挂上这个脚本，在检查器里填名字、描述、冷却、持续时间和音效。玩家身上可以直接用的能力有：`start_dash()`（冲刺并无敌）、`set_offhand()`（副手武器）、`aim_direction`（瞄准方向）。

**加一种新敌人**：新建一个脚本 `extends Enemy`，重写 `_think(delta)`，返回每帧想移动的方向。基类提供了现成的能力：
- `chase_direction()`：追玩家，会绕障碍物
- `shoot_bullet()`：开枪
- `has_line_of_sight_to_player()`：判断能不能看到玩家
- `spawn_minion()`：召唤或分裂出新敌人，房间会自动把它算进这一波

然后复制一份 `slime.tscn`，换上新贴图和脚本，最后在 `room.gd` 顶部的 `ENEMY_TABLE` 刷怪表里加一行，填上从第几层开始出现和出现的权重。想要特殊动画（比如蝙蝠扇翅膀）就重写 `_animate()`。

**加一个新 Buff**：在 `game_state.gd` 的 `BUFFS` 里加一条，再在 `apply_buff()` 里写上效果。

**小地图和全屏地图**：`ui/minimap.gd` 用地牢生成器输出的网格数据来画，只显示去过的房间和与之相邻的房间。宝箱房是黄点，商店是绿点，Boss 房是红点，青色小点是玩家。方块大小和间距可以改 `ROOM_SIZE` / `SPACING`。全屏地图（`ui/map_overlay.tscn`）复用同一个脚本，只是勾选了 `fit_all`，会把所有已知房间按整数倍放大铺满画面。

**商店**：每层有一个商店房，卖一把随机武器、生命药水、能量瓶和神秘强化（随机一个 Buff），价格随楼层上涨。商品种类和价格在 `room.gd` 的 `_spawn_shop()` 里调，效果在 `shop/shop_item.gd` 里。买武器时背包满了，换下来的武器会放在地上。

**障碍物和敌人寻路**：战斗房会随机选一种布局（四根石柱 / 中央石墩 / 四道矮墙 / 只放木箱），再随机撒几个木箱；Boss 房有四根石柱可以躲弹幕。布局都在 `dungeon/obstacle_layouts.gd` 里，加新布局就在 `_battle_pillars()` 的 match 里加一个分支。石柱就是 TileMap 里的墙，挡路也挡子弹；木箱被打几下会碎，有概率掉金币或能量。

地牢生成后会烘焙一张导航网格（`dungeon.gd` 的 `_bake_navigation()`，只解析墙和石柱，不包括木箱）。敌人能直接看到玩家时直线追，被挡住时沿导航网格绕路，写法见 `Enemy.chase_direction()`；新敌人想追玩家，调用它就行。

**宝箱**：宝箱房有一个金宝箱，打开掉一把武器和药水；清完战斗房有 60% 的概率在房间中央出现补给箱，打开掉金币和能量（概率改 `Room.SUPPLY_CHEST_CHANCE`，掉落内容改 `props/chest.gd` 的 `_spawn_loot()`）。

**可交互物体**：按 E 交互的东西（地上的武器、商店商品、宝箱）都是带 `interact(player)` 方法的 Area2D。玩家走近时调用 `player.add_interactable(self)`，离开时调用 `remove_interactable(self)`，按 E 会和最近的那个交互。加传送点、NPC 对话都可以照这个写。

**音效和音乐**：在任何脚本里调用 `Sound.play(音频资源, 音量dB, 音高随机幅度)` 播放音效，`Sound.play_music(音频资源)` 切换背景音乐；常用的音效都在 `autoload/sound.gd` 里定义成了常量。每把武器的开火音效在它的 `WeaponData` 资源里配置。同一个音效 30 毫秒内只会播放一次，所以大量子弹同时命中也不会爆音。背景音乐有两首：地牢和 Boss 战，进入 Boss 房时自动切换。暂停菜单里可以分别调节音乐和音效的音量，设置保存在 `user://settings.cfg`。

替换音频：直接覆盖 `assets/audio/` 下的同名文件就行，也可以用 .ogg 或 .mp3，改一下引用路径即可。背景音乐需要在 Godot 的导入面板里把 Loop Mode 设为 Forward。推荐用 [jsfxr](https://sfxr.me/) 制作 8-bit 音效。

**调难度**：
- 楼层数：`GameState.FINAL_FLOOR`
- 房间数：`room_count()`
- 敌人血量成长：`enemy_hp_mult()`
- 每波敌人数量和远程怪比例：`Room._random_wave()`
- 每个房间刷几波：`Room._on_trigger_body_entered()`

**画面和光照**：
- 地牢整体压暗成暖色调（`dungeon.tscn` 里的 `Ambient` 节点，改颜色就能调亮暗和色调），再用光源照亮：玩家身上一盏、墙上的火把（会闪烁）、传送门、枪口火光和爆炸。
- 子弹、掉落物、特效不受光照影响，在暗处也很醒目。
- 墙是 2.5D 的：下方是地板的墙画成砖墙正面（偶尔挂旗帜、有破洞），上方是墙顶，左右是侧墙，墙根下的地板带阴影（`dungeon.gd` 的 `_paint_tiles()`）。
- 地面有 8 种石板花纹，偶尔有骷髅装饰（`DECOR_CHANCE` 调密度）。
- 房间门是从地里升起的地刺。
- 角色和敌人有脚下阴影、走路颠动、脚步扬尘，受击会飘伤害数字，屏幕四周有暗角。

**角色和敌人动画**：贴图是横向的动画条，一共 8 帧：前 4 帧待机，后 4 帧跑动（和 0x72 素材包的排列一致），会按状态自动播放。每帧的宽高不限，角色在 `CharacterData.hframes` 里填帧数，敌人在场景的 Sprite2D 上设 `hframes = 8`；只有一帧的贴图也能用，会退回到代码做的挤压和颠动。

**0x72 素材是怎么接进来的**：原始图集在 `assets/0x72/`，旁边的 `tiles_list_v1.3.txt` 记录了每个精灵的坐标和帧数。`assets/sprites/` 下的角色、敌人、近战武器、宝箱、木箱、药水、金币、地刺门和地牢瓦片，都是按这份清单从图集里裁出来的（武器转成了朝右，寒冰法杖换成了冰蓝色）。想换别的角色或怪物，照着清单里的名字（比如 `skelet`、`ogre`、`masked_orc`）裁出 8 帧动画条就行。

**换美术**：直接替换 `assets/sprites/` 下的同名 PNG 就行，尺寸可以不同。`tiles.png` 里第一行是 8 种地板 + 墙根阴影，第二行是墙（普通砖墙、4 色旗帜、2 种破洞、墙顶、左右侧墙、虚空），碰撞配置在 `dungeon/tileset.tres`。推荐的免费素材：
- [0x72 16x16 DungeonTileset II](https://0x72.itch.io/dungeontileset-ii)：风格和元气骑士很像
- Kenney 的 Tiny Dungeon

**中文字体**：目前用的是系统字体回退，桌面端能正常显示。导出到网页或手机前，建议下载一款开源像素中文字体（如 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font)、[Ark Pixel](https://github.com/TakWolf/ark-pixel-font)），在 `ui/theme.tres` 里设为默认字体。
