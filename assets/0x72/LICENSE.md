# 16x16 DungeonTileset II（v1.3）

- 作者：0x72，官方页面：https://0x72.itch.io/dungeontileset-ii
- 许可证：**CC0**（公有领域，可以随意使用、修改和商用，不强制署名）
- `0x72_DungeonTilesetII_v1.3.png` 是原始图集，`tiles_list_v1.3.txt` 列出了每个精灵的名字、坐标、尺寸和帧数。
- `assets/sprites/` 里的角色、敌人、近战武器、道具和地牢瓦片都是从这张图集里裁出来的（部分重新着色或拼接）。

本份图集取自开源游戏 DungeonRush（https://github.com/yujqiao/dungeonrush）附带的副本，
其 README 注明该图集为 0x72 的 CC0 素材。DungeonRush 里的其他美术和音乐是别的作者的、许可证不同，本项目没有使用。
想换成最新的 v1.7，可以从官方页面下载后替换，并按新的坐标清单重新裁切。
